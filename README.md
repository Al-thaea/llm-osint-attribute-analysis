# llm-osint-attribute-analysis
Проєкт для аналізу відкритих джерел (OSINT): від парсингу сирого тексту до формування детального віртуального портрета цільової особи. / OSINT analysis framework: from raw text parsing to constructing detailed virtual psychological portraits powered by AI.

Автоматизована система для збору та глибокого психолінгвістичного аналізу дописів Telegram-користувачів за допомогою Великих Мовних Моделей (LLM).

Цей інструмент дозволяє збирати повідомлення з публічних Telegram-каналів або експортованих чатів та формувати комплексний неявний профіль автора: психологічні особливості (DISC, Big Five), демографічну інформацію, професійні інтереси, комунікаційний стиль, цифрову гігієну та ризики соціальної інженерії.

## Структура проєкту

Набір складається з 4 основних скриптів:

* **`parser_open_channels.py`** — 웹-скрапер публічних Telegram-каналів. Збирає текстові дописи та URL-адреси зображень без використання Telegram API (через вебінтерфейс `t.me/s/`).
* **`parser_open_chats.py`** — Парсер HTML-експортів Telegram. Дозволяє витягнути історію повідомлень конкретного користувача з вивантаженого групового чату.
* **`analyzer.py`** — Основний модуль аналітики. Формує запити до LLM (підтримуються OpenAI GPT-4o та Gemini 2.5 Flash), передає текст і зображення та отримує структурований профіль у форматі JSON.
* **`results.py`** — Головний модуль-оркестратор. Керує процесом збору даних, запускає аналітику та генерує форматовані текстові звіти (`report.txt`) і JSON-результати (`disc_results.json`).

## Встановлення та налаштування

1. **Встановіть залежності:**
   Для роботи скриптів потрібні наступні бібліотеки:
   ```bash
   pip install requests beautifulsoup4 openai google-genai
   ```

2. **Налаштуйте API ключі:**
   Відкрийте файл `analyzer.py` та вставте ваші API ключі замість заглушок:
   ```python
   LLM_PROVIDER = "openai"  # або "gemini"
   GEMINI_API_KEY  = "YOUR_GEMINI_API_KEY"
   OPENAI_API_KEY  = "YOUR_OPENAI_API_KEY"
   ```

## Використання

Є два основні сценарії збору даних: з публічного каналу або з експортованого чату.

### Сценарій 1: Аналіз публічного Telegram-каналу
Відредагуйте словник `SOURCES_TO_ANALYZE` у файлі `results.py`:
```python
SOURCES_TO_ANALYZE = {
    "Channel_Name": {
        "url": "https://t.me/example_channel",
        "target_user": None,
        "months_limit": 12 # Зібрати дані за останні 12 місяців
    }
}
```
Запустіть скрипт:
```bash
python results.py
```
Скрипт автоматично збере повідомлення та створить звіт у папці `Results/Channel_Name/`.

### Сценарій 2: Аналіз користувача з групового чату
Якщо канал приватний або вас цікавить конкретна людина у великому чаті:
1. Експортуйте історію чату через Telegram Desktop (формат HTML).
2. Відкрийте `parser_open_chats.py` та налаштуйте змінні в кінці файлу:
   ```python
   EXPORT_FOLDER = r'path/to/ChatExport_folder'
   TARGET_USER = "username_in_chat"
   OUTPUT_FILE = "Results/Channel_Example/posts.json"
   ```
3. Запустіть парсер: `python parser_open_chats.py`
4. Потім додайте цей шлях як джерело у `results.py` (або просто запустіть аналіз зі збереженого `posts.json`).

## Формат результатів

Аналізатор формує звіт, що охоплює наступні категорії:
* **DISC та Big Five:** Оцінка психотипів особистості.
* **Демографія:** Прогнозований вік, регіон, рівень освіти.
* **Професійний профіль:** Галузь, рівень експертизи, ставлення до роботи.
* **Стиль комунікації:** Реєстр налаштувань, емоційність, використання жаргону/емодзі.
* **Цінності та мотивація:** Що є рушійною силою індивіда, що викликає гордість чи гнів.
* **Ризики соціальної інженерії:** Детальний перелік потенційних векторів впливу (напр. надмірне поширення геолокації чи корпоративних секретів).
